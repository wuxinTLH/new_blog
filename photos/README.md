# 穿搭相册

把照片放在此目录（项目根目录 photos），命名为 nz_1.jpg、nz_2.png、nz_3.webp 等。

- 支持 jpg / jpeg / png / webp / avif / gif，后缀与 nz 前缀不区分大小写。
- 编号从 1 开始，按数字排序（nz_2 在 nz_10 前），不要求连续；同一编号建议只保留一张。
- 图片保持完整比例展示，不裁剪。请先压缩大图、清除 EXIF 地理位置等隐私信息，并只放愿意公开的照片。
- 添加或删除图片后重新运行 npm run build；线上需提交并推送，等待 Actions 部署。生产站点不会在访问时扫描 GitHub 目录。
- 没有匹配照片时显示相册准备中；只有一张时不自动播放；多张时每 3 秒切换，支持首尾循环，可暂停、键盘左右键或手机左右滑动。
- 鼠标悬停、键盘焦点在相册内、相册离开视口或浏览器后台时暂停。系统开启减少动态效果时不自动播放。
